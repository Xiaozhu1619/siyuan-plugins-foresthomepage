# 森林主页 · Forest Homepage

> **免责声明**：本插件是 **vibe coding 的产物**——整份代码是在对话里由 AI 生成的，未经逐行人工审查，可能存在 bug，或与你的主题、其他插件产生样式冲突。介意请勿使用，使用风险自负。

一个思源笔记的**卡片式主页**：一屏之内看到最近打开过的文档、随手记下的灵感、一个可以翻月的日历，还有一个直接搜全文的搜索框。支持自定义背景图与问候语，卡片可以随手拖动排序。

## 开发灵感

森林主页的开发灵感源自于大自然的森林：这里没有喧嚣、没有嘈杂，只有安安静静的你。

森林主页要做一个没有任何复杂功能的、简单展示和直达内容的入口，让你快速进入状态，这便足矣。

## 界面与用法

**进入主页**：顶栏最左侧的主页图标，或命令面板里的「打开主页」。主页是一个独立的页签，可以和其他文档页签自由切换。右键顶栏图标可以快速进入设置或重跑引导。

想让思源**一启动就落在主页**？打开 **设置 → 打开思源时进入主页**（设置面板最上方的第一项）即可：默认关闭，下次启动生效。

- **问候语（三行）**
  - 第一行：根据时间自动变化 + 你的名字，例如「晚上好，小明」
  - 第二行：一句短句，默认每天换一句（内置诗句），也可以在设置里固定成自己的句子
  - 第三行：日期与时间
- **搜索框**：在时间下方。输入关键词即可同时搜索**文档标题**与**文档正文**，`↑` `↓` 选择，`Enter` 打开，`Esc` 清空。主页内按 `⌘ / Ctrl + K` 可以直接聚焦搜索框。
- **最近打开**：最近查看过的文档，点一下直接打开；右上角可手动刷新。
- **灵感随记**：在输入框写下想法，`⌘ / Ctrl + Enter` 或点「记录」保存；鼠标移到某条灵感上可删除。
- **日历**：`‹` `›` 翻月，「今天」跳回当月。有记录的日期下方带小圆点，点一下查看当天的文档；空白日期可以一键新建日记。
- **快速访问**：手动 Pin 的文档集中在这里，可以分组。Pin 的三种姿势：
  - 鼠标移到「最近打开」或搜索结果里的某一行，点右侧的**图钉**；
  - 在任意文档行上**右键**，菜单里选「固定到快速访问」，或直接归入某个分组；
  - 点卡片右上角的 **＋ 添加**，在对话框里搜索文档，点一行即可固定/取消。
  卡片默认整行宽。**横向拉得越宽，同一高度能排下的列数越多**（1/4 宽 1 列 → 半宽 3 列 → 整行 6 列），也就是"拉宽 = 看到更多已 Pin 的内容"。
  - **自适应排布**：列数按条目的**实际可用宽度**算，电脑与平板拉宽后自动多列排布；手机竖屏排两列、横屏与平板更多列，超窄屏老实退回单列 —— 屏有多大就用多大。
  - **长标题截断**：文件名过长时只显示前面一小段并以 `…` 收尾，鼠标悬停可看完整标题，不会把布局撑坏。
  - **拖到别的分组**：条目可以直接拖进另一个分组完成分类。
  - **调整分组顺序**：抓住分组标题左侧的六点抓手上下拖，顺序即时生效并自动保存。
  - **未分类空了就不显示**：全部 Pin 都归进了自定义分组时，「未分类」不再占位置；一旦有内容又会自动出现。
- **统计**：笔记总数、今日使用时长、今日写作字数。右上角可手动刷新。
  - **笔记总数**来自思源自己的数据库，准确。
  - **使用时长思源本身不记录**，由插件在后台按 30 秒一次的心跳在本地累计：窗口可见且 10 分钟内有操作才计时。所以它从你安装插件那天开始算，之前的时间补不回来；设置里可以清空重来。
  - **写作字数**同样是思源没有的数据，这里按内容块统计：今天新建或改动过的块，其当前字数合计。也就是说，改一个旧段落会把该整段的字数计进去，这是个近似口径。
- **拖动排序**：鼠标按住卡片任意空白处拖动即可换位（手机上按住卡片左上角的抓手）。顺序会被记住。
- **拖动缩放**：按住卡片右下角的斜线抓手拖动即可改大小。宽度只在 **1/4 · 1/3 · 1/2 · 2/3 · 整行** 五档之间吸附，高度只在 **矮 · 标准 · 高 · 超高** 四档之间吸附，所以怎么拖都保持整齐；缩放时旁边会显示当前档位。
- **加卡片 / 删卡片**：统一在 **设置 → 显示的卡片** 里勾选；旁边还有「全部显示 / 全部隐藏 / 恢复默认顺序」。首次安装的引导向导用的是同一份清单，以后插件新增卡片也会自动出现在这两处。

## 首次安装

装好启用后会自动弹出**引导向导**，三步走：

1. 填一个称呼（会出现在问候语第一行）
2. 勾选想在主页看到的卡片
3. 选一张背景图（可跳过）

之后随时可以在 **设置 → 插件 → 森林主页 → 设置 → 重新运行引导** 里再跑一次。

## 安装

**推荐**：在思源里打开 **设置 → 集市 → 插件**，搜索「森林主页」下载启用即可。

手动安装：

1. 到 [Releases](https://github.com/Xiaozhu1619/siyuan-plugins-foresthomepage/releases) 下载 `package.zip`
2. 解压得到插件文件夹，确保文件夹名与 `plugin.json` 里的 `name` 一致
3. 放到工作空间的 `data/plugins/` 下
4. 重启思源，在 **设置 → 插件** 中启用

## 数据与隐私

- **不联网**，不读取你的文档正文到插件存储里。搜索通过思源本地的 SQL 接口完成，只返回命中的标题与路径。
- **灵感**保存在插件私有存储 `data/storage/petal/<插件名>/inspirations.json`，会随思源云同步一起走。
- **快速访问**保存在同目录的 `quickaccess.json`，只记文档 id / 标题 / 所在分组；分组只是这里的一层分类，不会改动思源的笔记本结构。
- **设置**保存在同目录的 `settings.json`。
- 用「选择图片」上传的背景图会放进工作空间的 `assets` 目录，可以用思源自带的资源管理清理。

## 已知限制

- 卡片是**固定档位**尺寸，内容超出时在卡片内部滚动，不会把卡片撑高。
- 「今日使用时长」从插件首次运行当天开始累计，装上之前的使用时间无法追溯。
- 「今日写作字数」是**内容块口径的近似值**，不是逐字的写作量账本。
- 窗口变窄时会自动收窄可用档位（中等宽度只允许半宽/整行，窄屏一律整行），窗口变宽后恢复你保存的尺寸。
- 日历的圆点表示「这一天创建过文档」，并非严格的日记标记。
- 搜索是 `LIKE` 匹配，不是分词检索；文档量特别大时首次搜索会有轻微延迟。
- 拖动排序在手机上是按住抓手拖动，不能整卡拖动（否则和页面滚动冲突）。
- 只读模式 / 发布模式下，「灵感随记」和设置修改不会写入磁盘。
- 开启「打开思源时进入主页」后，主页会在启动约 0.3 秒后出现 —— 那是思源把上次的标签恢复完、再做完一次标签栏重算的时间，插件要等过它才不会和思源的收尾动作抢焦点。
